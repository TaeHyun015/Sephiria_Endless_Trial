# Sephiria Endless Trial
[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

**Endless Trial**은 Sephiria의 비공식 시련 모드입니다. 별도의 시련 전투 공간에서 단계를 진행하고, 5단계마다 상인·보상 공간을 방문할 수 있습니다.

배포 파일과 아래 설치 방법은 Windows용 Steam 설치를 기준으로 합니다. [v1.0.0 릴리즈 노트](RELEASE_NOTES_v1.0.0.md)

## 다운로드와 설치

1. [최신 릴리즈](https://github.com/TaeHyun015/Sephiria_Endless_Trial/releases/latest)에서 **`Endless_Trial.zip`**을 다운로드합니다.
2. 게임을 완전히 종료합니다.
3. ZIP을 Sephiria 설치 폴더의 `AddOns`에 압축 해제합니다. 최종 구조는 다음과 같아야 합니다.

   ```text
   Sephiria/
   └─ AddOns/
      └─ Endless_Trial/
         ├─ Endless_Trial.dll
         ├─ endless_trial_floor
         ├─ metadata.json
         └─ Endless_Trial/
            └─ trial_bg.png
   ```

4. 게임을 실행합니다. 기존 버전을 업데이트할 때도 게임을 종료한 상태에서 같은 위치에 압축을 풀어 덮어씁니다.

ZIP 안에 이미 `Endless_Trial` 폴더가 있으므로 `AddOns/Endless_Trial` 안에 ZIP을 다시 풀어 폴더가 한 단계 더 중첩되지 않도록 확인하세요.

## 플레이 방법

- 멀티존의 시련 입구 포탈에서 호스트가 저장 슬롯을 선택해 입장합니다. 멀티플레이에서는 입구 주변에 모든 플레이어가 모여야 합니다.
- 시련의 석판에서 단계를 시작합니다. 진행 중에는 시련 전투 공간에 엔딩 크레딧 BGM이 재생됩니다.
- 5단계마다 열리는 포탈로 상인·보상 공간에 갈 수 있습니다. 모두 전투 공간으로 돌아오면 다음 단계를 시작할 수 있습니다.
- 저장 및 돌아가기 포탈로 진행 상황을 저장하고 나갈 수 있습니다. 시련 저장 슬롯은 3개이며, 멀티플레이의 저장은 호스트가 관리합니다.

## 자동 업데이트

새 버전이 공개되면 게임 시작 시 업데이트 확인 팝업이 표시됩니다. 수락하면 릴리즈의 `Endless_Trial.zip`을 다운로드하고 SHA256을 확인한 뒤, 게임이 종료되면 모드 파일을 교체하고 게임을 다시 실행합니다. 취소하면 현재 버전으로 계속 플레이할 수 있습니다.

자동 업데이트가 인식하려면 릴리즈가 **Published** 상태여야 하고, 태그와 ZIP 내부 `metadata.json`의 `modVersion`이 같은 버전이어야 합니다. 릴리즈 파일명은 정확히 `Endless_Trial.zip`이어야 합니다. 설치된 버전과 같은 버전의 릴리즈는 업데이트로 표시되지 않습니다.

시련 저장 파일은 모드 설치 폴더의 ZIP에 포함되지 않습니다. 업데이트 ZIP에 세이브 파일을 넣지 마세요. 게임이나 모드를 재설치하기 전에는 중요한 저장 데이터를 별도로 백업하는 편이 좋습니다.

## 문제 해결

- **모드가 보이지 않을 때:** 위 폴더 구조와 `metadata.json`, DLL, `endless_trial_floor` 파일을 확인하세요.
- **자동 업데이트가 나타나지 않을 때:** 새 릴리즈의 태그가 설치 버전보다 높은지, 릴리즈가 Draft 또는 Prerelease가 아닌지, ZIP 파일명이 맞는지 확인하세요.
- **오류를 제보할 때:** 게임 버전, 모드 버전, 재현 순서와 `C:\Users\<사용자>\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log`의 관련 부분을 함께 남겨주세요. 로그를 공개하기 전에는 개인 정보를 확인하세요.

## 라이선스와 권리

이 모드는 TEAM HORAY의 공식 제품이 아닙니다. Sephiria의 이름, 원본 게임 에셋과 음악에 대한 권리는 각각의 권리자에게 있습니다. 모드의 배포가 해당 원본 자료에 대한 별도의 재사용 허가를 의미하지는 않습니다.

이 저장소에는 현재 모드 코드의 재사용 조건을 정한 오픈 소스 라이선스를 지정하지 않았습니다. 라이선스가 없는 공개 저장소의 소스는 자유로운 수정·재배포가 허용된 것으로 간주할 수 없습니다. 모드 코드의 공개 라이선스는 별도로 결정할 예정입니다.
