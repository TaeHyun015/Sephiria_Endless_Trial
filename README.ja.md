# Sephiria Endless Trial

[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

**Endless Trial** は、Sephiria の非公式試練 MOD です。専用の試練戦闘エリアでステージを進め、5ステージごとに商人と報酬のエリアを訪れることができます。

以下の配布ファイルとインストール手順は、Windows 版 Steam を対象としています。[v1.0.0 リリースノート（韓国語）](RELEASE_NOTES_v1.0.0.md)

## ダウンロードとインストール

1. [最新リリース](https://github.com/TaeHyun015/Sephiria_Endless_Trial/releases/latest)から **`Endless_Trial.zip`** をダウンロードします。
2. ゲームを完全に終了します。
3. ZIP を Sephiria のインストールフォルダー内にある `AddOns` に展開します。最終的なフォルダー構成は次のとおりです。

   ```text
   Sephiria/
   └─ AddOns/
      └─ Endless_Trial/
         ├─ Endless_Trial.dll
         ├─ endless_trial_floor
         ├─ metadata.json
         └─ Endless_Trial/
            └─ trial_bg.png
   ```

4. ゲームを起動します。既存のバージョンを手動で更新する場合も、ゲームを終了してから同じ場所に展開し、古いファイルを上書きしてください。

ZIP にはすでに `Endless_Trial` フォルダーが含まれています。フォルダーが余分に一階層増えないよう、`AddOns/Endless_Trial` ではなく `AddOns` に展開してください。

## 遊び方

- マルチゾーンの試練入口ポータルで、ホストがセーブスロットを選んで入場します。マルチプレイでは全員が入口の近くに集まる必要があります。
- 試練の石板からステージを開始します。ステージ進行中は、試練戦闘エリアでエンディングクレジットの BGM が流れます。
- 5ステージごとに商人と報酬のエリアへ向かうポータルが開きます。全員が戦闘エリアに戻ると、次のステージを開始できます。
- セーブして戻るポータルから進行状況を保存して退出できます。試練用のセーブスロットは3つあり、マルチプレイではホストがセーブを管理します。

## 自動更新

新しいバージョンが公開されると、ゲーム開始時に更新確認のポップアップが表示されます。承諾すると、リリースの `Endless_Trial.zip` をダウンロードして SHA256 ハッシュを確認し、ゲーム終了後に MOD のファイルを置き換えてゲームを再起動します。キャンセルすると、現在のバージョンでそのまま遊べます。

自動更新の対象にするには、リリースが **Published** 状態であり、タグのバージョンと ZIP 内の `metadata.json` にある `modVersion` が一致している必要があります。リリースファイル名は正確に `Endless_Trial.zip` としてください。インストール済みと同じバージョンのリリースは、更新として表示されません。

試練のセーブファイルは、MOD のインストールフォルダーに置く ZIP には含まれません。更新用 ZIP にセーブファイルを入れないでください。ゲームや MOD を再インストールする前に、重要なセーブデータを別途バックアップすることをおすすめします。

## 問題が起きた場合

- **MOD が表示されない:** 上記のフォルダー構成と、`metadata.json`、DLL、`endless_trial_floor` があるか確認してください。
- **自動更新が表示されない:** 新しいリリースのタグがインストール済みバージョンより新しいこと、リリースが Draft または Prerelease ではないこと、ZIP のファイル名が正しいことを確認してください。
- **不具合を報告する:** ゲームのバージョン、MOD のバージョン、再現手順と、`C:\Users\<ユーザー名>\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log` の関連箇所を添えてください。ログを公開する前に個人情報が含まれていないか確認してください。
